# 정선 FC: 90분의 백룸

정선의 역·탄광·아우라지·민둥산을 모티프로 만든 축구 백룸 공포 탈출 웹 게임입니다. 첨부된 소년 캐릭터가 축구공을 지키며 다섯 선수의 기억을 깨우고 출구를 찾습니다.

## 바로 플레이하기

Windows PowerShell에서 다음 명령을 실행합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 개발 서버가 표시한 주소를 엽니다.

## 조작

- `WASD` 또는 방향키: 이동
- `SPACE` 길게 누른 뒤 놓기: 충전 슛
- `SHIFT`: 질주
- `R`: 멀어진 공 회수
- `P` 또는 `ESC`: 일시정지
- 모바일: 화면 방향키, 질주, KICK, 회수 버튼

## 게임 구성

1. 라민 야말 — 고한역 무한 대합실 / 신호 드리블
2. 엘링 홀란 — 사북 탄광 슛 터널 / 압력 해제
3. 크리스티아누 호날두 — 정선선 VAR 복도 / 멈춘 프리킥
4. 손흥민 — 아우라지 양발 교차로 / 두 갈래의 답
5. 네이마르 주니오르 — 민둥산 페인트 미로 / 마지막 속임수

각 방에서 공으로 표식 3개를 순서대로 작동시키고 EXIT 골대에 득점하면 다음 기술이 해금됩니다. 공과 멀어지면 그림자 심판의 추격 속도가 빨라지지만, 심판에게 공을 맞히면 즉시 사라지고 그 방에서는 다시 나타나지 않습니다.

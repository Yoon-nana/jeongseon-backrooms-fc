# 정선 FC: 90분의 백룸

정선의 실제 관광지 사진이 끝없는 축구 백룸으로 변한 공포 탈출 웹 게임입니다. 첨부된 소년 캐릭터가 축구공을 지키며 14명 선수의 기억을 깨우고 가리왕산의 마지막 출구를 찾습니다.

## 바로 플레이하기

Windows PowerShell에서 다음 명령을 실행합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 개발 서버가 표시한 주소를 엽니다.

## 조작

- `WASD` 또는 방향키: 이동
- `SPACE` 길게 누른 뒤 놓기: 충전 슛
- `SHIFT`: 질주
- `R`: 멀어진 공 회수
- `P` 또는 `ESC`: 일시정지
- 모바일: 화면 방향키, 질주, KICK, 회수 버튼

## 14개 방

1. 라민 야말 — 나전역 무한 대합실 / 신호 드리블
2. 엘링 홀란 — 사북 탄광 슛 터널 / 압력 해제
3. 크리스티아누 호날두 — 정선아리랑열차 VAR 복도 / 멈춘 프리킥
4. 손흥민 — 아우라지 양발 교차로 / 두 갈래의 답
5. 네이마르 주니오르 — 여량 천년의숲 페인트 미로 / 깊은 속임수
6. 해리 케인 — 눈 쌓인 사북 페널티 리프트 / 빙점 피니시
7. 에밀리아노 마르티네스 — 화암동굴 세이브 벙커 / 마지막 선방
8. 리오넬 메시 — 아리랑박물관 곡선 복도 / 왼발의 궤적
9. 비니시우스 주니오르 — 민둥산 억새 윙 / 속도의 잔상
10. 주드 벨링엄 — 아라리촌 90+5 / 이어지는 추가시간
11. 킬리안 음바페 — 병방치 스피드 전망대 / 절벽 끝 가속
12. 알리송 베케르 — 동강 나리소 세이브 수문 / 세 겹의 수비선
13. 부카요 사카 — 정선아리랑시장 컷인 골목 / 다섯 번의 컷인
14. 호나우두 나자리우 — 가리왕산 전설의 돔 / 마지막 호나우두

## 난이도 곡선

표식은 `1 → 2 → 3 → 4 → 5개`, 동시에 등장할 수 있는 그림자 심판은 `0 → 1 → 2 → 3명`으로 증가합니다. 1~2단계에는 심판이 없고, 3단계부터 등장합니다. 후반으로 갈수록 첫 등장 시간이 18초에서 5초까지 짧아지고 재등장 간격도 34초에서 9초까지 줄어듭니다.

움직이는 공으로 그림자 심판을 맞히면 그 심판은 즉시 사라집니다. 다만 4단계 이후에는 방마다 설정된 간격이 지나면 빈자리에 새 심판이 나타날 수 있습니다. 공과 150px 이상 떨어지면 심판 속도가 약 38% 증가합니다.

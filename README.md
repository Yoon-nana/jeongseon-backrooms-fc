# 정선 FC: 90분의 백룸

정선의 역·탄광·아우라지·민둥산·화암동굴·설원·운동장을 모티프로 만든 축구 백룸 공포 탈출 웹 게임입니다. 첨부된 소년 캐릭터가 축구공을 지키며 열 선수의 기억을 깨우고 출구를 찾습니다.

## 바로 플레이하기

Windows PowerShell에서 다음 명령을 실행합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 개발 서버가 표시한 주소를 엽니다.

## 조작

- `WASD` 또는 방향키: 이동
- `SPACE` 길게 누른 뒤 놓기: 충전 슛
- `SHIFT`: 질주
- `R`: 멀어진 공 회수
- `P` 또는 `ESC`: 일시정지
- 모바일: 화면 방향키, 질주, KICK, 회수 버튼

## 게임 구성

1. 라민 야말 — 고한역 무한 대합실 / 신호 드리블
2. 엘링 홀란 — 사북 탄광 슛 터널 / 압력 해제
3. 크리스티아누 호날두 — 정선선 VAR 복도 / 멈춘 프리킥
4. 손흥민 — 아우라지 양발 교차로 / 두 갈래의 답
5. 네이마르 주니오르 — 민둥산 페인트 미로 / 깊은 속임수
6. 해리 케인 — 하이원 설원 페널티 리프트 / 빙점 피니시
7. 에밀리아노 마르티네스 — 화암동굴 세이브 벙커 / 마지막 선방
8. 리오넬 메시 — 아리랑 곡선 복도 / 왼발의 궤적
9. 비니시우스 주니오르 — 민둥산 억새 윙 / 속도의 잔상
10. 주드 벨링엄 — 정선 종합운동장 90+5 / 마지막 추가시간

각 방에서 공으로 표식 3개를 순서대로 작동시키고 EXIT 골대에 득점하면 다음 기술이 해금됩니다. 1~2방은 입문, 3~5방은 보통, 6~8방은 어려움, 9~10방은 악몽 난이도이며 단계가 오를수록 그림자 심판의 등장 시간이 짧아지고 속도가 빨라지며 표식 판정 반경이 작아집니다. 심판에게 공을 맞히면 즉시 사라지고 그 방에서는 다시 나타나지 않습니다.
